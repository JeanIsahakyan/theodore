One change, one space.

A space is a fresh copy of your repository on its own branch. The agent works there, so your checkout stays untouched and several changes can run at once. When it's done, the space becomes a pull request.

Built around the agents you already pay for.

Your agents, your machine

Claude Code, Codex and Gemini run on your computer with your own accounts. Theodore never sees your code or your keys.

Your phone is the remote

Follow every space, answer questions from a notification, start new work and send photos or files. Everything between devices is end-to-end encrypted.

Open source

The desktop app, the phone app and the cloud are on GitHub. Read it, build it, or run the cloud yourself.

How a change ships.

  1. Describe the change

    Pick a project and say what you want, from the desktop or your phone. Theodore opens a space for it.

  2. The agent works

    It reads, edits and runs your tests in the space. Split big work into sub-spaces that run in parallel.

  3. You answer when asked

    Questions and plans wait for you as a notification. One tap, and the agent continues.

  4. Review and ship

    Read the diff, leave comments for the agent, then open the pull request and merge it, all from Theodore.

Start a space, then go for a walk.
